## A. Tujuan Praktikum
1. Memahami sintaks dasar JavaScript dan penyisipan file eksternal pada dokumen HTML[cite: 9].
2. Menggunakan variabel, tipe data, operator, percabangan (`if-else`, `switch`), perulangan, dan fungsi (`function`)[cite: 9].
3. Menampilkan informasi output melalui `console.log()`, `alert()`, `prompt()`, dan manipulasi DOM.
4. Memanipulasi konten dan gaya elemen HTML melalui Document Object Model (DOM)[cite: 9].
5. Membuat interaksi form sederhana serta melakukan validasi input[cite: 9].
